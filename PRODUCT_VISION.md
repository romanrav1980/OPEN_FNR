# Product Vision OPEN FNR

## 1. Видение

OPEN FNR - промышленная платформа прогнозирования спроса и пополнения запасов для крупной торговой сети, которая соединяет ML-прогнозирование, управление промо, расчет заказов, контроль запасов, бизнес-процессы и объяснимые решения в едином контуре.

Цель продукта - перейти от разрозненных Excel-процессов, ручных корректировок и локальных правил к единой управляемой системе, где прогноз и заказ формируются прозрачно, ежедневно, масштабируемо и с измеримым бизнес-эффектом.

## 2. Продуктовая Формула

```text
OPEN FNR = Forecasting + Replenishment + Process Engine + Explainable UI + Governance
```

Система должна отвечать на пять ключевых вопросов:

1. Сколько покупатели купят?
2. Сколько товара нужно иметь?
3. Сколько нужно заказать?
4. Почему система предлагает именно такое решение?
5. Кто должен проверить или согласовать исключение?

## 3. Целевая Ценность

| Направление | Ценность |
| --- | --- |
| Продажи | снижение потерянных продаж из-за out-of-stock |
| Запасы | снижение избыточных остатков и замороженного капитала |
| Промо | точнее планировать uplift, поставки и post-promo stock |
| Fresh | балансировать доступность и списания |
| Операции | уменьшить ручную работу планировщиков |
| Управление | получить прозрачные KPI, audit trail и ownership |
| IT | заменить hardcoded-процессы управляемым process engine |

## 5. Область Продукта

### Входит

- регулярный прогноз спроса;
- промо-прогноз и uplift;
- расчет projected stock;
- расчет demand projection;
- order proposals;
- multi-echelon replenishment;
- fresh и shelf-life;
- lifecycle SKU;
- exception management;
- ручные корректировки;
- согласование и публикация;
- process engine на BPMN/DMN/CMMN;
- BI и операционные рабочие места;
- monitoring, audit, governance.
- supplier collaboration;
- procurement optimization;
- shelf space and capacity optimization;
- supply chain diagnostics;
- true inventory;
- store task management;
- workload forecasting.

### Не Входит В Базовую Версию

- оптимизация цен;
- автоматическое создание промо-календаря;
- управление персоналом магазинов;
- замена ERP/WMS/MDM;
- realtime-прогноз на каждый чек;
- marketplace/SaaS-зависимости;
- компоненты с AGPL/GPL/SSPL/BUSL в обязательном контуре.

## 6. Принципы Продукта

| Принцип | Описание |
| --- | --- |
| Explainable by design | каждое решение должно быть объяснимым |
| Human-in-the-loop | пользователь проверяет исключения, а не весь объем |
| Process-driven | бизнес-процессы не хардкодятся, а исполняются через Process Engine |
| Forecast is not order | прогноз спроса отделен от расчета заказа |
| Active matrix only | не считаем пустой декартов куб |
| Version everything | данные, модели, прогнозы, заказы, процессы и правила версионируются |
| Apache-2.0 compatible | стек бесплатный, self-hosted, permissive-license |
| CPU-first | production-контур строится на EPYC CPU-кластере |

## 7. Продуктовые Метрики Успеха

- улучшение WAPE против baseline;
- снижение Bias;
- рост service level;
- снижение out-of-stock;
- снижение lost sales;
- снижение overstock;
- снижение fresh waste;
- рост proposal acceptance rate;
- снижение ручной нагрузки;
- соблюдение SLA расчета;
- снижение количества критичных исключений.

## 8. Целевая Картина

Пользователь открывает Control Tower утром и видит:

- расчет завершен;
- прогноз опубликован;
- заказы сформированы;
- критичные исключения назначены владельцам;
- промо с риском дефицита подсвечены;
- fresh-риски видны;
- выгрузка в ERP/WMS прошла;
- бизнес-эффект измеряется.

OPEN FNR должен стать не просто ML-системой, а операционной платформой управления спросом и запасами.
