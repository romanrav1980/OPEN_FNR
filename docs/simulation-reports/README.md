# Historical Simulation Reports

This directory stores mandatory Historical Replenishment Simulation reports before Parallel Run.

Minimum Supplement 1 requirements:

- at least 52 weeks of historical rolling simulation;
- at least 20% of active stores;
- at least 50% of category turnover coverage;
- at least 2 promo waves and 1 seasonal cycle;
- OPEN FNR proposed orders compared against actual historical orders;
- metrics: simulated OOS rate, simulated overstock, simulated waste for fresh, proposal vs actual delta.

Parallel Run must not start without a positive HTML report in this directory.
