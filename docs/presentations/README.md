# OPEN FNR Presentations

HTML presentations for major sprint blocks.

These presentations are different from test reports:

- test reports prove that a sprint/test cycle passed;
- block presentations explain what was built, how users work with it and how
  developers should understand the module structure.

## Required Structure

Each presentation must include:

- purpose of the sprint block;
- module structure;
- business processes with BPMN/DMN/CMMN references;
- user scenarios with screenshots;
- developer map: code, API, data, process artifacts, tests;
- links to test reports;
- current limitations;
- next sprint plan.

## Storage

Use this path pattern:

```text
docs/presentations/<block-name>/index.html
```

Screenshots should be stored in:

```text
docs/presentations/<block-name>/screenshots/
```
