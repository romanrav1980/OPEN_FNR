OPEN FNR / I1-I5

Загрузка реальных данных для прогноза и пополнения

Блок I1-I5 переводит систему от mock-данных к промышленным входным потокам: POS, WMS, ERP, MDM/PIM и промо-система. Все batch-потоки имеют контракт, manifest, idempotency key, raw ClickHouse landing и Airflow DAG skeleton.

Что реализовано

POS sales

Чековые строки продаж и возвратов для фактического спроса и backtesting.

WMS inventory

Остатки, открытые заказы и товары в пути для projected stock.

ERP commercial

Цены и статусы экспорта заказов для коммерческих расчетов и сверки.

MDM/PIM

SKU, магазины, lifecycle, fresh, supplier и routing keys.

Promo plan

SKU, скидка, цена, место и мощность выкладки, период и store scope.

Audit config

Бизнес-аудит включен по умолчанию и отключается только настройкой.

Бизнес-процесс загрузки

Happy path

Source system publishes manifest with row count, checksum and idempotency key.

Airflow DAG validates schema and lands immutable raw data in ClickHouse.

DQ gates validate completeness, duplicates, references and freshness.

Clean canonical layer becomes available for forecast, projected stock and replenishment.

Error path

Schema, checksum or DQ blocker stops clean publication.

Process Engine creates Data Owner, Promo Planner or Integration Owner task.

Business action is recorded in audit when OPEN_FNR_AUDIT_ENABLED=true.

Reprocessing uses the same idempotency key and avoids duplicate clean rows.
