Shared Policy Layer

Аннотация: тестируем переход от endpoint-local проверок к общему policy layer. Такой слой нужен, чтобы role checks, service account checks и object-level scope checks были единообразными для всех бизнес-процессов.

UI вызывает /security/policy-check и показывает активную policy версию в Admin Console.
