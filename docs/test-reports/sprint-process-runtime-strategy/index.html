Process Runtime Strategy

Аннотация теста

Проверяем, что OPEN FNR явно различает runtime-deployable BPMN и governance-only DMN/CMMN. Это нужно, чтобы команда разработки и бизнес не считали DMN/CMMN автоматически исполняемыми в Flowable OSS, пока для них не утверждён отдельный runtime adapter и тестовый контур.

Тестирование бизнес-процесса

ШагЧто делаемЗачемОжидаемый результатФакт
1 Запрашиваем runtime strategy API. Получить единый контракт по BPMN/DMN/CMMN execution boundary. API возвращает 3 стратегии по типам артефактов. Endpoint добавлен и покрыт тестом.
2 Проверяем BPMN strategy. Убедиться, что процессы действительно идут в Flowable runtime. BPMN имеет стратегию runtime_deploy. 38 BPMN runtime-deployable.
3 Проверяем DMN/CMMN strategy. Зафиксировать границу между governed artifacts и runtime execution. DMN/CMMN имеют стратегию governed_artifact. Runtime adapter будет отдельным решением.
