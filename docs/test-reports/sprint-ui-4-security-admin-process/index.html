UI-4: Security, Admin And Process UI

Annotation. We test whether an administrator and process owner can inspect users, service accounts, access requests, access review, task inbox and process deployment gates from the UI. This protects production security and business-process operations before pilot.

Process operations Check task inbox, audit trail, deployability, runtime strategy and BPMN quality gate. Process owners need task execution and deployment governance in one operational UI. Process operations markers are visible. Passed by static UI test.
