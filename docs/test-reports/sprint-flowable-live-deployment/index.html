Тестирование бизнес-процесса

ШагЧто делаемЗачемОжидаемый результатФакт
1 Проверяем доступность Flowable REST engine. Подтвердить, что процессный runtime реально поднят. Engine отвечает 200 при валидных dev credentials. Flowable 7.1.0 доступен.
2 Собираем deployability report по всем BPMN. Не пропускать в runtime процессы с критическими дефектами модели. Система разделяет deployable и requires_model_fix. 37 BPMN deployable, 1 BPMN требует исправления.
3 Нормализуем BPMN для Flowable deployment. Пустые serviceTask/businessRuleTask в проектной модели должны иметь безопасный runtime placeholder. Flowable принимает runtime-safe BPMN без KIE/Drools зависимости. businessRuleTask заменяются на serviceTask с delegateExpression.
4 Загружаем runtime-safe `.bar` в Flowable. Получить реальный deployment id и доказать работоспособность контура. Flowable возвращает HTTP 201 и deployment id. Deployment id получен.
5 Фиксируем blocker BPMN-модели. Не скрывать дефекты процесса под техническим успехом деплоя. Для каждого blocker есть путь, element id и причина. source_batch_accepted_gateway не имеет outgoing sequence flow.
