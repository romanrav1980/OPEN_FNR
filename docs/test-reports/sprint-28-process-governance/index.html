OPEN FNR Sprint 28: Production Process Governance

Аннотация: тестируем production discipline для BPMN/DMN/CMMN: versioning, artifact validation, process test suite, risk decision, deployment approval, migration safety, release notes и rollback.

UI-тестирование

  1. Открываем Process Governance.
  2. Проверяем version list: bulk_auto_approval_decision v1 deployed, v2 review.
  3. Проверяем change request: from v1 to v2, medium risk, migration required.
  4. Проверяем actions: Review, Deploy, Rollback.
  5. Проверяем migration panel: existing instances continue.
