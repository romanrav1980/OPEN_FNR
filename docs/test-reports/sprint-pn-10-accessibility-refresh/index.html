PN-10 Process Navigator - accessibility and refresh

Дата: 2026-05-29. Цель: проверить, что Process Navigator стал удобнее для операторов без мыши, показывает окружение, свежесть данных и использует интервалы обновления из конфигурации.

Аннотация теста

Мы тестируем доступность и обновление карты бизнес-процессов, потому что в промышленной эксплуатации операторы, аудиторы и менеджеры должны понимать, какой контур они смотрят, насколько свежи данные и как управлять картой клавиатурой. Такой тест снижает риск ошибочного анализа скриншотов из разных окружений.

UI-тесты

Шаг Что делаем Зачем Ожидаемый результат Фактический результат
1 Открываем Process Navigator после production build. Проверить, что новые элементы не ломают shell. Страница рендерится, screenshot создается. Пройдено.
2 Проверяем environment selector. Скриншоты DEV/STAGE/PROD должны быть однозначны. Контур выбирается из `VITE_OPEN_FNR_ALLOWED_ENVIRONMENTS`. Добавлен selector и query `env` во все Process Navigator API calls.
3 Проверяем freshness strip и ручной refresh. Оператор должен видеть свежесть карты и иметь безопасное ручное обновление. Интервал берется из env, ручной refresh увеличивает refresh tick. Добавлены auto-refresh, generated_at, data freshness и кнопка Refresh.
4 Проверяем клавиатурную навигацию. Process Navigator должен соответствовать базовым ожиданиям WCAG 2.1 AA. Tab проходит по controls/nodes, Escape возвращает zoom на уровень выше. Добавлены focus-visible states и Escape handler.
5 Проверяем touch target и reduced motion. Интерфейс должен быть пригоден для планшетов и пользователей с reduced motion. Интерактивные элементы не меньше 44 CSS px, motion уважает media query. CSS обновлен.

Тесты бизнес-процессов

Процесс Что проверяем Почему Результат
Process monitoring by environment Все map/detail/alert запросы получают выбранный `env`. DEV, STAGE и PROD не должны смешиваться в операционной картине. Готово.
Operational refresh Карта обновляется по интервалам из frontend config. Алерты и SLA должны обновляться без ручного перезахода. Готово.
Keyboard investigation Оператор может перейти по controls и вернуться zoom out через Escape. Разбор инцидента должен быть возможен без мыши. Готово.
