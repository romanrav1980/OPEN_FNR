Аннотация: тестируем planogram/shelf слой: shelf capacity, display capacity, direct-to-shelf, store zones and auditable shelf exceptions.

UI-тестирование

  1. Открываем Shelf Space.
  2. Проверяем planogram table с зонами front и fresh-wall.
  3. Проверяем warning: requested 140 при display capacity 120.

  5. Проверяем действия Filter zone, Review warning, Approve.
