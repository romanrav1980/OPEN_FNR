OPEN FNR Sprint 27: Production Replenishment Scale

Аннотация: тестируем промышленный контур replenishment: projected stock partitions, 3.6M order proposals, bulk approval, proposal retention и async export package.

UI-тестирование

  1. Открываем Production Replenishment Scale.
  2. Проверяем industrial run: 3.6M proposals, 108M projected stock rows, runtime 94 minutes.
  3. Проверяем partition table: fresh и grocery partitions в статусе approval_ready.
  4. Проверяем bulk actions: Apply filter, Bulk approve, Queue export.
  5. Проверяем exception panel: runtime/constraint/partition failure открывает scale exception case.
