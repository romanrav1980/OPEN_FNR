UI, API и интеграционный тест

Capacity TMS Target

Аннотация: тестируем экспорт сглаженного capacity-плана в TMS через configurable target adapter. В DEV/TEST используется local fallback, в STAGE/PROD endpoint задается через OPEN_FNR_TMS_CAPACITY_EXPORT_URL.

Скриншот

UI получает affected order moves из GET /capacity/plans.
