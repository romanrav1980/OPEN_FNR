OPEN FNR Process Navigator Map

Аннотация: тестируем первый backend-контракт отдельного модуля навигации по бизнес-процессам. Цель проверки - убедиться, что система может показать процессный ландшафт как карту: от домена до конкретного BPMN-процесса, шага, SLA-алерта и audit-context.

Что тестируем и зачем

Область Зачем Ожидаемый результат Фактический результат
Process map zoom 0 Бизнесу нужен верхнеуровневый обзор доменов процессов. Карта возвращает доменные кластеры. Пройдено: есть forecast и replenishment кластеры.
Semantic zoom При приближении процесс должен распадаться на составляющие. Zoom 3 содержит BPMN steps и sequence edges. Пройдено: BPMN nodes/edges добавлены.
Alerts Карта должна показывать несоответствия, а не только красивую схему. Есть BPMN quality challenges и SLA alerts. Пройдено: quality и escalated task алерты видны.
BPMN drill-down Операционный пользователь должен провалиться в конкретную модель. Для forecast review возвращается BPMN-граф. Пройдено: узлы и связи процесса возвращены.
Boundary check DMN/CMMN не должны ошибочно открываться как BPMN-граф. Non-BPMN drill-down отклоняется. Пройдено: API возвращает 400.
