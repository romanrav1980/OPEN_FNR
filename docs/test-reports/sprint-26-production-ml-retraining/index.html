OPEN FNR Sprint 26: Production ML And Retraining

Аннотация: тестируем production ML governance: retraining result, backtesting, WAPE/Bias, drift detection, shadow run, release approval and rollback. Такой тест нужен, чтобы модель нельзя было выпустить без воспроизводимого gate и audit trail.

UI-тестирование

  1. Открываем Model Monitoring V2.
  2. Проверяем candidate: regular-demand-lgbm-v2, status shadow.
  3. Проверяем метрики: WAPE 14.9%, baseline WAPE 18.4%, Bias -0.4%, drift low.
  4. Проверяем release steps: backtesting, drift detection, shadow run, approval.
  5. Проверяем actions: Approve, Release, Rollback.
