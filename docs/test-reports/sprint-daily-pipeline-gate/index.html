UI, API и бизнес-процесс тест

Daily Pipeline Gate

Аннотация: тестируем дневной диспетчерский сценарий, который объединяет загрузку источников, DQ, clean publication и готовность feature mart. Такой тест нужен, чтобы бизнес и IT видели не отдельные технические эндпоинты, а понятную цепочку сменного запуска.

Скриншот

Скриншот снят при поднятых frontend и backend. UI обращается к POST /pipeline/daily-gate/run и показывает live-стадии процесса.

Итог

Сквозной daily gate готов как backend API, UI-блок и автоматизированный процессный тест. Ограничение: при отсутствии реальных source-файлов live gate честно показывает blocked-сценарий; для happy path используется pilot landing pack.
