OPEN FNR UI-1 Routed Foundation

Аннотация

Проверяется базовый UI-фундамент: маршруты рабочих областей, состояние активного маршрута, централизованная конфигурация API/service URL и наличие help-сносок, которые связывают UI с постановками задач и бизнес-процессами. Такой тест нужен, чтобы дальнейшая продуктовая доработка UI не расползалась и не вносила сетевой хардкод.
