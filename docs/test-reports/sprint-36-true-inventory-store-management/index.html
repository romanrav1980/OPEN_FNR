Sprint 36 / True Inventory And Store Management

OPEN FNR - отчет по true inventory и задачам магазина

Тестируем расчет виртуального остатка, confidence score, создание задачи магазина, подтверждение промо-выкладки, завершение задачи с counted qty/comment/photo placeholder и влияние store feedback на quality flags.

Что и зачем тестируем

True Inventory

Проверяем расчет virtual stock из system stock, POS movements, deliveries и corrections.

Store Task Loop

Проверяем, что низкая уверенность остатка создает задачу магазина и возвращает корректирующую обратную связь.
