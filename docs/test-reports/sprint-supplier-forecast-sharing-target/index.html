Supplier Forecast Sharing Target

Аннотация: тестируем отправку прогноза поставщику через управляемый target adapter: local fallback для DEV/TEST и HTTP endpoint через OPEN_FNR_SUPPLIER_FORECAST_SHARE_URL для stage/prod.

Скриншот

UI получает supplier forecast share rows из GET /supplier-collaboration/forecast-share.
