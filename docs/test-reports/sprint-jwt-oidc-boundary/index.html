JWT / OIDC Boundary

Аннотация: тестируем первый production security boundary: при включенном OPEN_FNR_AUTH_ENABLED рабочие API требуют Bearer JWT, а DEV/TEST могут использовать явно включенный bypass header. Такой способ нужен, чтобы не смешивать локальную разработку и stage/production доступы.

UI читает /metadata и показывает auth boundary status в Admin Console.
