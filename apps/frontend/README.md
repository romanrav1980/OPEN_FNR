# OPEN FNR Frontend

React/Vite shell for the OPEN FNR development control tower.

## Sprint 0 Scope

- Static control tower screen in VSCode-inspired noble red style.
- Links to local development services.
- API proxy from `/api/*` to the local FastAPI backend.

## Commands

```powershell
cd apps/frontend
npm.cmd install
npm.cmd run dev
```

Development URL: `http://127.0.0.1:13000`.
