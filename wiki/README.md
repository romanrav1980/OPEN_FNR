# OPEN FNR Wiki

This wiki is the navigation layer for OPEN FNR.

Principles:

- simple Markdown first;
- short pages with clear ownership;
- canonical documents stay linkable;
- every important decision has a visible home;
- open questions are explicit;
- concepts are named consistently;
- docs are useful for humans before they are complete.
