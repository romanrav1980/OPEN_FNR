# Glossary

| Term | Meaning |
| --- | --- |
| Active matrix | active `store x SKU` combinations used for forecasting and replenishment |
| Forecast | expected customer demand |
| Regular forecast | forecast without promo uplift |
| Promo uplift | additional demand caused by promo |
| Total forecast | regular forecast plus promo uplift |
| Demand projection | replenishment demand after considering inventory and constraints |
| Projected stock | future stock level by date |
| Order proposal | recommended order quantity |
| Safety stock | buffer stock for demand and supply uncertainty |
| Presentation stock | minimum stock required for shelf presentation |
| Display stock | promo display stock for additional placement |
| Stock-out | product unavailable for sale |
| Lost sales | estimated sales lost due to unavailability |
| Overstock | stock above target or business limit |
| Fresh | perishable categories with shelf-life constraints |
| Shelf-life | product lifetime before expiration |
| FEFO | first-expired-first-out |
| Phase-in | introduction of a new SKU |
| Phase-out | planned withdrawal of a SKU |
| Termination date | date after which ordering is blocked |
| BPMN | process modeling and execution notation |
| DMN | decision tables for business rules |
| CMMN | case management notation |
| Flowable | accepted open-source process engine |
| WAPE | weighted absolute percentage error |
| Bias | systematic forecast over/under prediction |
